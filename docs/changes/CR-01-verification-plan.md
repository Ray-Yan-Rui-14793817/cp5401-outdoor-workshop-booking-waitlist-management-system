#### Independent FIFO and boundary oracles

For W05/W06 and any other test using a third or fourth participant, add each fictional participant as a `DemoUser` with a unique `user_id` and `Role.PARTICIPANT` to the exact fixture's `DemoState.users`. Match every seeded registration owner to a participant in that state. Resolve the actor against that same state and assert the expected stable ID and role before exercising a valid action. Assert the intended operation outcome and exact resulting state. An absent ID reaches INVALID_ACTOR and belongs in a separate identity rejection case. Keep the hosted seed and selector unchanged. Source: [author feedback 5](../reviews/L7-human-review.md#author-feedback).

For W05/W06, use full capacity-one workshop A. The owner of CONFIRMED R10 cancels at C-1s. Current waiters R13 and R18 have sequences 3 and 8 and equal creation times. Put R18 first in the stored list and give that participant an earlier alphabetical name. R11 at sequence 1 is already CANCELLED. A separate full workshop B has a current sequence-1 waiter. Expected result: A/R10 becomes CANCELLED and A/R13 becomes CONFIRMED, both with the decision timestamp. A/R18 keeps sequence 8 and displays position 1. A/R11 and all of B remain identical. A has one confirmed place and zero remaining. The ID and sequence counters retain their initial values. Repeat with seeded timestamps placing R18's join earlier than R13's while both joins still precede cancellation. The expected result stays the same. These fixtures detect selection by list, name or timestamp, cross-workshop selection, selection of withdrawn rows and multiple promotion. Declare the expected results independently of the queue code.

Use an otherwise-valid active fixture at each W12 boundary. Book uses spare capacity, Join uses full capacity with a new eligible participant, confirmed Cancel uses the owner's active record and a live queue, and Withdraw uses a separate owner's active waiting row. For creation, use a separate valid draft. Promotion is observed from the cancellation result.
