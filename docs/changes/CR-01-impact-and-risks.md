## Risk review

Use High where a plausible operation or code error can break a critical allocation, ownership, deadline or state guarantee, or frustrate the intended user task. Use Medium where the primary effect is a bounded usability or review gap and a focused review can contain it. For mixed effects, classify the more consequential path and record the lower-impact limitation separately. These are qualitative planning estimates based on affected behaviour, exposure and uncertainty. A blocker is an unresolved condition that prevents progress or a justified decision, such as ambiguous action authority or missing required proof. It is separate from the High classification.
